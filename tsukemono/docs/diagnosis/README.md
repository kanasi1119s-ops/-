# 人物の絵の診断（直す前／直した後）

ドットキャラの「コマごとの色のずれ」と「動きの不自然さ」を、直す前と直した後で同じ物差しで比べるための記録。

- `before/` … 直す前（コミット `145890f` の絵）。
  - `report.md`: キャラ別・動作別の問題の数。
  - `summary.json`: コマごとの数値。
  - `sheet_<キャラ>.png`: 4倍のコンタクトシート。左から順にポーズ集0〜、驚き、怒り、歩く0〜15。
  - `overview.png`: 全キャラの1倍の一覧。キャラごとに1行、コマごとに1列。
- `manifest.json` … どのキャラのどの動作が、どの絵をどこにそろえて描くか。ゲームの定義から作る。

コンタクトシートでは、どのコマも立ち位置（縦の線）と足の裏（横の線）をそろえて置いている。線からのずれが、ゲームの中で見える位置のずれになる。

## 作り直し方

```
node tools/sprite_manifest.mjs > docs/diagnosis/manifest.json
python3 tools/sprite_audit.py docs/diagnosis/manifest.json docs/diagnosis/before   # 直した後は after に
```

## 点検の項目（`tools/sprite_audit.py`。しきい値は summary.json の thresholds）

基準のコマは、キャラごとに「待つ」の1コマ目。

- **色**
  - 基準にない色: ΔE6 より遠い色の画素が2%以上。
  - 胴・髪（頭の上）・肌の主な色が、基準と ΔE20（肌は15）以上ちがう。
  - 主な色の系統が入れかわる: キャラの全色を10系統にまとめ、基準で8%以上の系統がそのコマでは2%未満、またはその逆。
  - 同じパーツの色が何通りあるか: ΔE15 以内を同じとみなし、多数派の色と少数派のコマを出す。
- **輪郭**
  - ふちの暗い色の一番多いものが、基準と ΔE10 以上ちがう。
  - ふちなのに暗くない画素が5つ以上ある（輪郭が途切れる。白い靴下や光った所など、もとからの絵も含む）。
- **形**
  - 足の裏の行が、決めた行とずれる。
  - 頭のてっぺんから足の裏までの高さが、基準と3ドット以上ちがう。
  - 頭の中心（立ち位置からの横のずれ）が、基準と4ドット以上ちがう。
- **きれいさ**
  - 半透明の画素。歩くコマの足もとの影（わざと半透明）は除く。
  - 3画素以下の浮いたかたまり。
- **動き**: となりのコマとの差。息づかいや沈みは、2ドットまでのずらしを許して一番小さい差で見る。驚き・怒りのわざとの跳ねは除く。
  - 変わった画素が35%（歩くコマは45%）を超える。
  - 頭が3ドット以上とぶ。
  - 待つ・買う・取る・漬ける・渡すで、頭の所が15%以上変わる。
  - 歩きの上下のゆれが1〜2ドットでない。
